One haiku about debugging, in the 5-7-5 syllable shape — a log line at
midnight, a stack trace pointing the finger, and the admission at the
end. Running main.py validates the shape and writes the haiku to
/output/entry.txt.

> Log line at midnight
> the stack trace points at my code
> my fault all along

## Run it
```sh
python3 main.py
```
